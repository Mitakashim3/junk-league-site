Privacy Policy

Last updated 10 November 2026

What this covers

Junk League Uploader is a private tool used only by the owner of the Junk League channels. It uploads and schedules Junk League's own videos on the owner's YouTube channel. No one else signs in to it, and it is not offered to the public.

YouTube API Services

Junk League Uploader uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What it accesses and why

  • Upload videos to the owner's YouTube channel, with titles, descriptions and a scheduled publish time.
  • Read the channel's own list of videos, so the same video is never uploaded twice.

It does not read comments, subscribers, viewing history or any data about other people.

What it stores

The sign-in token that Google issues is kept only on the owner's own computer. It is not sent to anyone else. The tool keeps the IDs of the videos it uploaded so it can tell which are done.

Sharing

No data is sold, shared with third parties or used for advertising. This website sets no cookies and collects no personal data. It is hosted by GitHub Pages, which may keep standard server logs under the GitHub Privacy Statement.

Removing access

Access can be removed at any time on the Google Account page Third-party apps and services. The stored token can be deleted from the owner's computer.
